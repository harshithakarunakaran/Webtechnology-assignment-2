# Question 1 — Student Registration Form

## Aim
To create a responsive student registration form using HTML5, CSS3 and JavaScript with client-side validation.

## Files
- `index.html` — registration form fields and page structure
- `style.css` — layout, colors, input styles and responsive design
- `script.js` — required-field, email, password and file validation

## How to run
1. Extract this folder.
2. Open `index.html` in a modern web browser.
3. Enter test values and press **Register Student**.
4. Try empty fields, an invalid email, a weak password, and an unsupported/large file to test validation.

## Validation included
- Full name and roll number
- Email address format
- Course selection
- Password length and character requirements
- Optional JPG, PNG or PDF upload, maximum 2 MB

## Important limitation
This is a front-end demonstration only. The form does not transmit or store student details, and client-side file checks are not a substitute for server-side validation.

## Conclusion
The student registration form was developed using HTML, CSS and JavaScript. CSS provides a responsive and user-friendly layout. JavaScript validates required fields, email format, password strength and file restrictions before showing a success message.
